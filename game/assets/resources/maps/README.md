# 인게임 맵 편집 가이드 (디자이너용) — Cocos 씬 방식 v2

맵은 **Cocos Creator 안에서** 편집합니다. 편집 씬은 빌드에 포함되지 않고,
**[내보내기]로 만든 `mapdata.json`** 을 게임이 읽습니다.

## 여는 법

1. Cocos Creator로 `game/` 프로젝트 열기
2. Assets 패널에서 **`mapedit/mapedit`** 씬 더블클릭 (resources 밖 — 빌드 미포함)
3. 위에서 내려다본 **청사진**이 보임 — 타일 격자 + 색 사각형(구역/배치물)

> 청사진은 정사각 격자(1타일 = 32px)입니다. 게임의 마름모(아이소)는 게임이 그립니다.
> **청사진의 좌하단 = 게임 화면의 하단 코너.**

## 구조 (Hierarchy)

```
MapRoot  ← MapEditRoot 컴포넌트 (맵 크기·재생성·내보내기)
├─ _바닥가이드      ← 배경판 (건드리지 말 것)
├─ tiles           ← 타일 전체가 펼쳐져 있음 — 타일마다 속성 편집
├─ zones/hub·dungeon ← 구역 (반투명 사각형)
├─ props           ← 배치물
└─ spawn           ← 플레이어 시작 (1개)
```

## 타일 편집 (구역 단위 ★)

전체 타일은 격자 그림(페이크)으로만 보이고, **편집 구역을 씌운 곳만 진짜 타일**이 펼쳐집니다
(에디터가 무거워지지 않게).

1. `MapRoot` 선택 → **addRegion 체크** → 반투명 편집 구역이 생김
2. 구역을 드래그로 이동(격자에 자동 스냅) · 사각 기즈모로 크기 조절 (최대 24×24)
3. 구역 선택 → Inspector **TileRegion → editTiles 체크** → 그 범위의 타일이 펼쳐짐
4. 타일 클릭(Shift 다중 선택) → **MapTile**: **img**(0 기본/1 마을/2 던전 — 색 즉시 반영) · **attr**(속성 번호)
5. 다른 곳을 편집하려면: 구역을 옮기거나, 다른 구역의 editTiles 체크
   → **수정한 값은 자동 보존**되고 타일 노드는 재사용됨
- **맵 크기 변경**: MapEditRoot의 **mapTiles** 수정 → 격자가 즉시 늘어남 (타일 노드 대량 생성 없음)

## 배치물

드래그 이동 · 사각 기즈모(T)로 크기 · Ctrl+D 복제 · Sprite Color로 색.
배치물 이름 = 종류: `shop` `counter` `gate` `crate` `lantern` `fence` `table` `pillar`.

## 존(구역)의 정의 — 타일이 원본

존 사각형은 없습니다. **타일의 zone 값이 곧 존**입니다:

| zone | 이름 | 게임 규칙 |
|---|---|---|
| 없음(0) | 미개방 | **이동 불가** — 존을 칠한 곳만 걸어다닐 수 있음 |
| 마을(1) | 마을 | 안전 — 몬스터 불가침, HP 회복 |
| 던전(2) | 던전 | 웨이브 스폰 |
| 통로(3) | 통로 | 몬스터 불가침, 회복·스폰 없음 (마을↔던전 이동로) |

⚠️ 플레이어 시작 위치(spawn)는 반드시 존이 칠해진 타일 위에 둘 것 — 아니면 시작부터 못 움직임.

마을을 넓히려면 타일 zone을 1로 칠하면 끝 — 모양 제한 없음.
이동불가는 zone이 아니라 **attr 1**로 칠합니다 (빨갛게 표시).

## 타일 이미지 규칙

`resources/maps/tiles/`에 **`{이미지ID}_{이름}.png`** (128×64 마름모, 여백 투명).
예: `1_auto.png`, `2_auto.png` … 타일의 img 값 = 파일명 앞 숫자.
이름 부분은 자유 — 아트 교체 시 같은 ID로 파일만 넣으면 됨 (현재 1~32 = 자동생성 테스트 타일).

## 저장 → 내보내기 → 확인 (중요: 3단계)

1. **Ctrl+S** (씬 저장)
2. `MapRoot` 선택 → **exportJson 체크** → 콘솔에 "내보내기 완료" 확인
   (이걸 해야 게임에 반영됩니다 — 씬 저장만으로는 반영 안 됨!)
3. **Play ▶ / F5** → 게임 확인

## 커밋

씬 + `resources/maps/mapdata.json` 둘 다 커밋 대상. 각자 Claude에게 "맵 올려줘".
