# 인게임 맵 편집 가이드 (디자이너용)

게임 맵은 **Tiled**(무료 맵 에디터)로 편집합니다. 코드·엔진 지식 불필요.

## 준비 (1회)

1. Tiled 설치 (무료): https://github.com/mapeditor/tiled/releases 에서 `Tiled-*_Windows-10+_x86_64.msi` 다운로드
   (공식 사이트 다운로드는 후원 페이지를 거침 — "No thanks, just take me to the downloads"를 누르면 무료)
2. Tiled에서 이 폴더의 `ingame_map.json` 열기

## 편집 규칙

맵은 **아이소메트릭 49×49 타일** (타일 128×64). 레이어 3개만 사용:

| 레이어 | 넣는 것 | 방법 |
|---|---|---|
| `zones` | 구역 (마을/사냥지대) | **사각형 도구(R)** 로 그림. Class에 `hub` 또는 `dungeon` 입력. 커스텀 속성 `tint`(string, `#RRGGBB`) = 바닥 톤 |
| `props` | 배치물 (건물·판매대·게이트 등) | **포인트 도구(I)** 로 찍음. 커스텀 속성: `kind`(string), `w`/`h`(int, 픽셀 크기), `tint`(string) |
| `walls` | 벽 (이동 차단) | **사각형 도구(R)** 로 그림. 속성 불필요 — 그린 곳은 못 지나감. **통로(게이트 길)는 벽 사이를 비워서** 표현 |
| `spawn` | 플레이어 시작 위치 | 포인트 1개만 |

- 겹치는 구역은 **좁은 쪽이 우선** (마을이 사냥지대 안에 있어도 마을로 판정됨)
- 레이어 이름·파일 이름(`ingame_map.json`)은 바꾸지 말 것
- ⚠️ **다른 사람(또는 AI)이 맵 파일을 수정했다면, 편집 재개 전 반드시 File → Reload** —
  Tiled가 "외부 변경" 팝업을 띄우면 무조건 Reload. 안 그러면 저장 시 상대 작업을 덮어씀
- 새 레이어/타일셋을 추가해도 게임은 무시함 (참고용으로는 자유)

## 저장 & 확인

1. Tiled에서 **저장 (Ctrl+S)** — 파일 형식은 JSON 그대로 유지
2. **Cocos Creator 창을 한 번 클릭** — 에디터가 바뀐 파일을 다시 읽어들임 (이 단계를 빼면 예전 맵이 그대로 보임!)
3. 게임 프리뷰(브라우저) **새로고침(F5)** → 반영
4. 좌상단 HUD에 `map: tiled` 로 뜨면 이 파일이 적용된 것 (`map: dev(fallback)` 이면 파일이 깨진 것 — 개발에 문의)
