## 1. 한 줄 방향

세계관: **이세계(異世界) 정육식당** (킥오프 확정) —
이세계 던전 옆 정육식당 주인이 몬스터를 썰어 **고기를 등에 한 조각씩 과장되게 쌓고**,
가게로 돌아와 **빠르게 팔아** 골드를 불리며, 그 골드로 **강화**해 더 깊은 던전으로
나아가는 **빠르고 시원한 픽셀아트 액션 타이쿤**.

- **핵심 재미 = 운반·리스크 테이킹** — "더 쌓을까 vs 지금 튈까" (결정)
- 구조: 사냥↔판매를 수시로 오가는 **연속 루프 (A안)** (결정)
- 광고식 즉각 만족 > 깊은 시뮬레이션
- 플랫폼: **모바일 세로형** 기준 + **웹 버전** 지원 (결정)
- 조작: **이동만.** 공격 등 나머지는 자동 (결정)
- 목표 수준: 단순 MVP가 아닌 **퀄리티를 올린 베타/출시급** (결정)

## 2. 코어 루프

```
사냥 → 적재(생고기, 등 뒤 스택) → 그릴(조리) → 재적재(구운 고기) → 판매 → 골드 → 강화 → 반복
```
짧은 세션을 반복하며 상점 성장 & 던전 진행. (2026-07-24 기획회의 — 조리 단계 추가, §9-a 참고)

## 3. 시그니처 — 등 뒤 고기 스택 ★

- 고기는 인벤토리 숫자가 아니라 **개별 오브젝트**로 등 뒤에 붙어 탑을 만든다
- **운반 한계** 존재 — 한계 도달 시 바닥 고기를 더 줍지 않음. **또한 공격도 불가**(§8, 결정 2026-08-07) — 땀 흘리기 등으로 표현
- 비주얼 6단계: 빈 몸 → 1~2 → 어깨 높이 → 키보다 높게 → 큰 고기탑 → 한계(광고식)
- 구현: 1~10개는 개별 스프라이트, 이상은 묶음 단위로 압축. 살짝 흔들림(관성) OK
- **최우선 프로토타입 대상** — 코어 비주얼 재미이기 때문

## 4. 맵 구조 — 씬 전환 없는 하나의 세계 (킥오프 확정)

> ※ "씬 전환 없음"은 **인게임(마을↔사냥지대)에만** 적용된다. 게임 실행 직후의 **인트로·로비는 별도 화면** — [specs/INTRO_LOBBY.md](specs/INTRO_LOBBY.md) 참고 (2026-07-24)

- **하나의 연속 맵, 2D 쿼터뷰 통일, 다이아몬드 형태** — 씬 전환·뷰 전환 없음
- **마을(허브)은 맵 하단 코너**: 판매대·손님 줄·강화 오브젝트
- 마을 위쪽 **영역 경계를 넘으면 사냥 지대가 그대로 펼쳐짐** (화이트아웃 서바이벌식)
- 사냥 지대: 웨이브·투사체·보스·고기 드랍·스택 — 멀리 갈수록 깊은 던전 영역
- 화면 스케일 (결정): **화이트아웃 플레이어블 애드 수준의 줌인** — 뱀서식 대규모 물량 연출 아님
- 규모 감각 (기획 초안): 한 영역 = 화면의 3~4배 넓이, 처치 시 리스폰. 동시 몬스터 수는 줌인 스케일에 맞게 재산정 (BALANCE)
- 단일 뷰이므로 뷰 전환/연출 불필요, 캐릭터·스택 스프라이트 하나로 통일

## 6. 플레이어

- 땅딸막한 몸 · 큰 앞치마 · 두툼한 팔 · 커다란 정육 칼(클리버). 거칠지만 정겨움
- 성장은 **앞치마·무기·장식으로만** 표현, 비율은 고정
- Lv.1 견습 → Lv.2 숙련 → Lv.3 명장 → Lv.4 전설
- **설정 (결정 — 2026-07-10)**: 이세계로 이송된 정육점 주인. 성격은 **금사빠 찐따** — 비서 NPC와의 관계가 코미디 톤의 축

### 6-a. 방향 — 4방향 (결정 2026-08-07)

- **플레이어는 동서남북 4방향**으로 움직이고, 방향마다 스프라이트를 갖는다 (idle · walk · attack 각 4방향)
- **몬스터는 좌우 2방향만 유지** — 물량 대비 체감이 작아 확장하지 않는다
- 종전 "플레이어 좌/우 2방향" 규정은 이 항목으로 대체됨
- ⚠ **확인 필요**: 북쪽(뒤돌아선 방향)을 볼 때 **등짐 고기 스택이 캐릭터를 가리는** 문제 — 스택을 반투명/축소할지, 그 방향만 스택 위치를 조정할지 아트·개발 협의 (임의 처리 금지)

| # | 강화 | 효과 |
|---|---|---|
| 1 | 공격력 | 타격 데미지 상승 |
| 2 | 이동속도 | 기본 이동속도 상승 |
| 3 | 운반 ★ | 최대 운반량·픽업 범위·이동 페널티 감소 — **스택 비주얼과 직결** |

- **공수 최소화를 위해 오브젝트는 3개만 배치** (결정) — ~~상점~~ 카테고리는 폐기(판매는 §9 자체 시스템으로 진행, 강화 대상 아님), ~~진행~~은 오브젝트가 아니라 **§7-c 맵 경계 게이트**로 이동

### 7-a. 강화 오브젝트 조작 (결정 — 2026-07-24 기획회의)

- 오브젝트 앞 **트리거 발판**을 밟으면 해당 카테고리 강화 팝업
- 팝업 표시 내용: **현재 내 스탯 + 보유 골드량 + 이번 강화로 오르는 스탯량 + 필요 골드**
- 구매 옵션: **1회 구매** / **10회 연속 구매**(자금 부족 시 가능한 만큼만) — 기존 결정 유지
- 존을 벗어나면 팝업 닫힘
- **미결(C9): 오브젝트 시각 변화 여부** — 강화할수록 오브젝트 외형이 바뀌는지(월드-인 성장감) 아니면 고정 형태인지. 아트 리소스 분량과 직결 → `DECISIONS.md` 참고

### 7-b. 강화 오브젝트 3종 (기획회의 확정 — 2026-07-24. 스케일: 책상/탁상 크기)

| 강화 | 오브젝트 | 구성 |
|---|---|---|
| ① 공격력 | 무기 손질대 | 탁상 + 숫돌 바퀴 + 걸린 칼 2~3자루 |
| ② 이동속도 | 신발 정비대 (임의 — 오브젝트명 미확정) | 탁상 + 튼튼한 장화·신발 진열 |
| ③ 운반 ★ | 운반구 공방 | 탁상 + 세워진 등짐 프레임 |

### 7-c. 진행(심층 해금) — 오브젝트 아님, 경계 게이트 트리거 (결정 — 2026-07-24 기획회의)

- 강화 오브젝트가 아니라 **맵 경계(마을↔사냥지대, 구역↔구역)의 문/통로에 트리거 발판**으로 처리
- 발판을 밟으면 팝업이 뜨고, 골드를 지불하면 그 경계 너머(다음 구역)가 해금됨
- **튜토리얼 겸용**: 게임 시작 시 마을→첫 사냥 지대로 넘어가는 최초 경계도 **동일한 발판+팝업 프로세스**를 거치되, **재화 소모 없이 무료 통과** — 트리거→팝업→확인이라는 조작 자체를 자연스럽게 익히게 하는 튜토리얼 역할

## 8. 던전 전투

- 빠르고·단순하고·시원하고·읽히고·짧은 세션. 조작은 이동뿐, 공격은 자동
- **공격 방향 규칙 (결정 2026-08-07)**: 자동 공격은 **플레이어가 바라보는 방향에 있는 몬스터만** 친다.
  등지고 있는 적을 향해 **자동으로 돌아서지 않는다** — 치려면 플레이어가 그쪽으로 방향을 틀어야 한다.
  ※ 종전 구현(표적 쪽으로 자동 회전)은 이 결정으로 **대체됨** (개발 2026-07-31 문의에 대한 답)
- **만재 시 공격 불가 (결정 2026-08-07)**: 등짐이 **운반 한계에 도달하면 공격을 하지 못한다.**
  고기를 더 줍지도 못하고 싸우지도 못하므로 **귀환 외에 할 일이 없어진다** — 운반·리스크 테이킹 축을 강화하는 장치.
  해당 상태는 **땀 흘리기 등 명확한 시각 표현**으로 알린다 (구체 연출은 추후 — 아트)
- **HP·피격 (결정):** 죽음/HP는 **항상 존재.** 몬스터마다 공격력·생명력 스탯이 있고 데미지는 그에 비례.
  피격은 **접촉(부딪힘)** 방식 — 투사체 몬스터는 이후 확장
- **죽음/손실 (결정):** 던전에서 죽으면 **그 런에서 얻은 고기·전리품만 잃는다.** 영구 강화·보유 골드는 유지
- 적 (실루엣 명확, 단순 형태) — **2026-07-24 기획회의: "고기 개연성 있는 친숙한 동물"로 컨셉 전환 (C8 방향 확정)**:

## 9. 고기 & 판매 — 타이쿤 요소 강화 (2026-07-24 기획회의 개편)

- 고기 **3등급** (일반 컷 / 프리미엄 컷 / 프라임 컷)
- 손님은 **자동 구매** — 주문 매칭 없음. 말풍선(고기 카테고리 아이콘)으로 수요 표현
- VIP 주문: 진행 강화로 해금되는 특별 퀘스트 (희귀 부위 요구, 큰 보상) — 세부는 제안 단계
- **판매는 생고기가 아니라 구운 고기로 진행** (결정) — 조리 단계가 코어 루프에 추가됨 (§2)

### 9-a. 조리·판매 플로우 (결정 — 2026-07-24 기획회의)

전체 흐름: 사냥 → 등짐(생고기) → **그릴 트리거** → 조리 → **그릴 수령 트리거**(구운 고기 재적재) → **판매 트리거** → 판매

1. **그릴 트리거**: 발판을 밟으면 등짐의 생고기가 **한 조각씩 그릴로 이송**(쭈르르르 연출) → 자동으로 조리됨
2. **그릴 수령 트리거**: 구워진 그릴 앞 발판을 밟으면 **구운 고기가 다시 플레이어 등 뒤에 재적재**됨 — ★ 플레이어가 직접 구운 고기를 지고 운반해야 함 (운반이 핵심 재미이므로 자동 서빙 아님)
3. **판매 트리거**: 발판을 밟으면 등짐의 **구운 고기**가 한 조각씩 판매대로 순차 이송(쭈르르르) → 손님이 사감
4. **골드 획득 (재확정 2026-08-07)**: 판매되는 **즉시 골드가 그대로 들어온다.**
   바닥에 떨어진 돈을 **줍는 스텝은 없다** — 불필요한 단계라 제거. 정산대(`checkout`)·회수위치(`money-pickup`)를 거치는 체인은 **폐기**
5. 중도 이탈 시 이송이 멈추고 안 넘어간 고기는 그대로 등짐에 남음(§9-a 기존 판매 정지 규칙과 동일) — 재진입 시 이어서 재개

**운반이 있는 곳과 없는 곳 — 의도적 구분**: 고기(생·구운)는 플레이어가 **직접 지고 나른다**(운반이 핵심 재미). 반면 **돈은 운반 대상이 아니다** — 판매 즉시 반영.

> ⚠ **개발 리워크 필요** (2026-08-07 재확인): 그릴 수령(플레이어 운반)은 반영 완료됐으나, **골드가 여전히 `정산대 → 회수위치` 체인으로 주워야 하는 구조**다. 판매 시점에 **즉시 `addGold`** 로 바꾸고 두 트리거 스텝을 제거할 것. 상세는 `HANDOFF.md` 참고

### 9-b. 손님 대기줄 (신규 — 2026-07-24 기획회의)

- 손님은 **타일당 2명씩** 배치되어 대기줄을 이룸
- **인내 게이지**: 판매대에 고기가 없으면 대기 손님의 인내 게이지가 차오름 — 꽉 차면 그 손님은 줄에서 이탈(구매 실패)
- **미결(C11)**: 인내 게이지의 표현 방식(바? 표정 변화? 등) — 아직 미정
- ⚠ 현재 구현(`CustomerSystem.ts`)은 **타일 1칸당 손님 1명** 단선 대기줄이라, "타일당 2명" 요구사항은 개발과 방식 확인 필요(레인 2개로 나누기 등) — `HANDOFF.md` 참고

### 9-c. 비서 NPC — **후순위 보류** (2026-07-24 기획회의: 공수 문제로 진행 여부 재검토)

> **상태: 보류.** 타이쿤 요소(조리·판매 플로우) 우선 완성이 먼저라는 팀 판단으로 후순위로 미룸. 작업량이 많아 이번 프로젝트 범위에서 진행되지 않을 수 있음. 아래는 컨셉 기록용 — 실제 구현 여부·시점은 추후 결정.

- **역할**: 플레이어가 이세계에 도착했을 때부터 함께하는 안내役 비서
- **컨셉 (결정)**: 엘프족·수인족 등 **이세계풍 아리따운 캐릭터**
- **위치**: 마을에 **고정 배치** — 강화 오브젝트처럼 정해진 자리에 항상 있음
- **알림 UI**: 돌발 퀘스트 등 안내 메시지가 발생하면 **화면 우측 상단에 비서의 얼굴(또는 전신)** + **말풍선**으로 표시
- **서사적 역할 (결정)**: 돌발 퀘스트·VIP 특수 오더를 통해 플레이어가 **던전을 더 깊이 탐험하도록 동기부여하는 열쇠**
- **친밀도 → 실플레이 효과 (결정, 방향성)**:
  - 친밀도 상승 구간마다 **강력한 무기 아이템 지급** (진행에 실질적 도움)
  - 비서가 직접 **호객 행위** — 손님을 더 끌어와 **판매 속도(골드 수급) 상승**
- **궁극 엔딩 (결정)**: **친밀도 100% 달성 = 결혼 엔딩**
- **상호작용 방식 (결정)**: **퀘스트보드** 형태. 비서 앞 존에 들어가면 퀘스트보드 UI가 뜨고, 돌발 퀘스트·VIP 오더를 받아 수행 → 완료 시 보상과 함께 **친밀도 상승** (대화 선택지·호감도 이벤트 방식 아님 — 마을 문법 "존 진입" 그대로 적용)
- **미결(C10, 보류)**: 퀘스트보드의 세부 — 퀘스트 종류·빈도·보상 구성, 퀘스트당 친밀도 상승량, 무기 지급·호객 효과의 정확한 수치 → `DECISIONS.md` 참고

### 10-a. HUD 최소화 원칙 (결정 — 2026-07-24, 화이트아웃 서바이벌·탕탕특공대 레퍼런스)

- **상시 코너 HUD 없음.** 골드·운반량을 화면 구석에 숫자로 상시 표시하지 않는다 — §10 "월드-인 우선"을 문자 그대로 적용
- **HP바는 캐릭터 위 플로팅(다이제틱)** — 화면 구석 위젯이 아니라 캐릭터 머리 위에 붙어 다님
- **HP바는 사냥지대(위협 존재)에서만 표시, 마을(안전지대)에서는 표시 안 함**
- **운반량은 등짐 스택 자체로 표현** — §3의 개별 스프라이트 스택이 곧 "재고" 정보이므로 별도 숫자 불필요
- **골드는 판매 시점에 "+N" 팝업으로만 등장** — 상시 카운터 대신 판매존에서 순간적으로 뜨는 연출. 누적 총액은 강화 팝업 안에서만 확인(§7-a)
- 몬스터도 동일하게 개별 HP바를 다이제틱으로 표시 (머리 위 작은 바)

### 10-b. 팝업 UI 규격 (2026-07-24)

**공통 규칙**
- **트리거 발판을 밟으면 자동으로 열리고, 존을 벗어나면 자동으로 닫힌다** — 닫기(X) 버튼 없음 (조작은 이동만 원칙)
- 화면 중앙 배치, 뒤쪽은 딤 처리
- 골드 부족 시 해당 버튼 비활성 (임의)

**① 강화 팝업** — 강화 오브젝트 3종 공통 (§7-a·§7-b)

```
┌────────────────────────────┐
│ 공격력 강화                 │  카테고리명
│ 무기 손질대                 │  오브젝트명 (작게)
├────────────────────────────┤
│ 현재 공격력            1    │
│ 강화 후            2 (+1)   │  증가분 강조 (초록)
│ 보유 골드            320    │
├────────────────────────────┤
│ [    1회 구매 — 50G     ]   │  주 버튼
│ [   10회 구매 — 550G    ]   │  보조 버튼
└────────────────────────────┘
```

- 표시 4종: **현재 스탯 · 강화 후 스탯(증가분) · 보유 골드 · 필요 골드** (결정)
- 10회 구매는 자금 부족 시 **가능한 만큼만** 구매 (결정)
- 구매해도 팝업은 닫히지 않고 **수치만 즉시 갱신** (임의)

**② 맵 해금 팝업** — 경계 게이트 (§7-c)

```
┌────────────────────────────┐
│ 다음 구역으로               │
│ 슬라임 굴                   │  목적지 지역 이름 (에디터 라벨)
├────────────────────────────┤
│ 해금 비용            500G   │
│ 보유 골드            320    │  부족하면 빨강
├────────────────────────────┤
│ [      해금하기       ]     │
└────────────────────────────┘
```

- **최초 마을→첫 사냥지대**: 비용 0, "무료 통과" 배지 표시 — 튜토리얼 역할 (결정)
- **이미 해금한 게이트**: 팝업 없이 그대로 통과 (임의)
- 지역 이름은 맵 에디터의 지역 라벨을 그대로 표시 (개발 2026-07-10 지역 규칙)
