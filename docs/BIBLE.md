## 1. 한 줄 방향

세계관: **이세계(異世界) 정육식당** (킥오프 확정) —
이세계 던전 옆 정육식당 주인이 몬스터를 썰어 **고기를 등에 한 조각씩 과장되게 쌓고**,
가게로 돌아와 **빠르게 팔아** 골드를 불리며, 그 골드로 **강화**해 더 깊은 던전으로
나아가는 **빠르고 시원한 픽셀아트 액션 타이쿤**.

- **핵심 재미 = 운반·리스크 테이킹** — "더 쌓을까 vs 지금 튈까" (결정)
- 구조: 사냥↔판매를 수시로 오가는 **연속 루프 (A안)** (결정)
- 광고식 즉각 만족 > 깊은 시뮬레이션
- 플랫폼: **모바일 세로형** 기준 + **웹 버전** 지원 (결정)
- 조작: **이동만.** 공격 등 나머지는 자동 (결정)
- 목표 수준: 단순 MVP가 아닌 **퀄리티를 올린 베타/출시급** (결정)

## 2. 코어 루프

```
사냥 → 적재(등 뒤 스택) → 귀환 → 판매 → 골드 → 강화 → 반복
```
짧은 세션을 반복하며 상점 성장 & 던전 진행.

## 3. 시그니처 — 등 뒤 고기 스택 ★

- 고기는 인벤토리 숫자가 아니라 **개별 오브젝트**로 등 뒤에 붙어 탑을 만든다
- **운반 한계** 존재 — 한계 도달 시 바닥 고기를 더 줍지 않음
- 비주얼 6단계: 빈 몸 → 1~2 → 어깨 높이 → 키보다 높게 → 큰 고기탑 → 한계(광고식)
- 구현: 1~10개는 개별 스프라이트, 이상은 묶음 단위로 압축. 살짝 흔들림(관성) OK
- **최우선 프로토타입 대상** — 코어 비주얼 재미이기 때문

## 4. 맵 구조 — 씬 전환 없는 하나의 세계 (킥오프 확정)

- **하나의 연속 맵, 2D 쿼터뷰 통일, 다이아몬드 형태** — 씬 전환·뷰 전환 없음
- **마을(허브)은 맵 하단 코너**: 판매대·손님 줄·강화 오브젝트
- 마을 위쪽 **영역 경계를 넘으면 사냥 지대가 그대로 펼쳐짐** (화이트아웃 서바이벌식)
- 사냥 지대: 웨이브·투사체·보스·고기 드랍·스택 — 멀리 갈수록 깊은 던전 영역
- 화면 스케일 (결정): **화이트아웃 플레이어블 애드 수준의 줌인** — 뱀서식 대규모 물량 연출 아님
- 규모 감각 (기획 초안): 한 영역 = 화면의 3~4배 넓이, 처치 시 리스폰. 동시 몬스터 수는 줌인 스케일에 맞게 재산정 (BALANCE)
- 단일 뷰이므로 뷰 전환/연출 불필요, 캐릭터·스택 스프라이트 하나로 통일

## 5. 아트 방향

- **정겨운 픽셀아트** — 따뜻하고 읽기 쉬움 (Dave the Diver 마을 톤 참고만, 직접 복제 금지)
- 강한 실루엣 — 모든 오브젝트는 멀리서도 기능이 읽혀야 함
- 톤: 살짝 어두운 코믹까지 OK, 호러·그로테스크는 아님 (처치 시 피 대신 고기가 팝)
- 색 = 기능: **붉은색=고기, 노랑=골드/보상, 보라·파랑=던전·마법**

## 6. 플레이어

- 땅딸막한 몸 · 큰 앞치마 · 두툼한 팔 · 커다란 정육 칼(클리버). 거칠지만 정겨움

### 7-a. 강화 오브젝트 조작 (가결정 — 2026-07-10, 기획)

- **트리거 = 존 진입.** 강화 오브젝트 앞 영역에 발을 디디면 **즉시 강화 팝업**이 뜬다 (게이지·상호작용 버튼 없음 — 마을 문법 "존 진입+자동처리" 그대로 적용)
- 팝업 내용: **스탯 예시(예: "힘 +1")** + **가격**
- 구매 옵션: **1회 구매** / **10회 연속 구매**(자금 부족 시 가능한 만큼만) — 편의성 제공
- 존을 벗어나면 팝업 닫힘
- **미결(C9): 오브젝트 시각 변화 여부** — 강화할수록 오브젝트 외형이 바뀌는지(월드-인 성장감) 아니면 고정 형태인지. 아트 리소스 분량과 직결 → `DECISIONS.md` 참고

## 8. 던전 전투

- 빠르고·단순하고·시원하고·읽히고·짧은 세션. 조작은 이동뿐, 공격은 자동
- **HP·피격 (결정):** 죽음/HP는 **항상 존재.** 몬스터마다 공격력·생명력 스탯이 있고 데미지는 그에 비례.
  피격은 **접촉(부딪힘)** 방식 — 투사체 몬스터는 이후 확장
- **죽음/손실 (결정):** 던전에서 죽으면 **그 런에서 얻은 고기·전리품만 잃는다.** 영구 강화·보유 골드는 유지
- 적 (실루엣 명확, 단순 형태):

| 적 | 타입 | 특징 |
|---|---|---|
| 슬라임 | 근접 | 느림, 튜토리얼 물량 |
| 고블린 | 근접 | 빠른 돌격·무리 압박 |
| 마법 박쥐 | 투사체 | 공중, 탄 발사 |
| 오우거 | 근접 | 크고 느림, 강타, 드랍 많음 |
| 던전 로드 (보스) | 보스 방 | bullet-hell 패턴, 대량 고기·해금 보상 |

- **드랍·픽업 (결정)**: **고기** = 처치 시 드랍율%로 바닥에 떨어짐, **걸어가서 주워야** 획득
  → **줍는 즉시 등 뒤 스택에 한 조각씩 쌓임** (§3, 운반의 무게)
- **레벨·XP·3택1 없음 (결정)**: 런 내 성장 시스템을 두지 않는다.
  **성장은 골드 영구 강화(§7) 하나로 일원화** — 강해지고 싶으면 고기를 팔아라
- **입장 재화 없음 (결정)**: 사냥 지대는 **자유 출입** — 하트/번개/골드 게이트 없음

## 9. 고기 & 판매

- 고기 **3등급** (일반 컷 / 프리미엄 컷 / 프라임 컷)
- 손님은 **자동 구매** — 주문 매칭 없음. 말풍선(고기 카테고리 아이콘)으로 수요 표현
- VIP 주문: 진행 강화로 해금되는 특별 퀘스트 (희귀 부위 요구, 큰 보상) — 세부는 제안 단계

### 9-a. 판매 메커니즘 (가결정 — 2026-07-10, 기획. 화이트아웃 서바이벌 판매대 방식)

- **트리거 = 존 진입.** 판매대 앞 영역에 발을 디디면, 등짐 고기가 **한 조각씩 순서대로 판매대로 이동**(쭈르르르 연출)
- 판매대에 도착한 고기를 손님이 하나씩 사가며 **골드가 서서히 상승** (일괄 정산 아님 — 눈에 보이는 점진적 처리)
- **중도 이탈**: 존 밖으로 나가면 **등 뒤에 남아있는 고기의 이동(이송)이 그 자리에서 멈춘다** — 아직 판매대로 넘어가지 못한 고기는 계속 등짐에 쌓인 채 남음. 이미 판매대로 넘어가 판매 처리된/처리 중인 고기만 골드로 인정
- 재진입하면 등짐에 남은 고기부터 다시 이송 재개

## 10. UI

- **월드-인 우선**: 비용=바닥 존, 재고=쌓인 고기, 수요=말풍선
- HUD 최소: 골드 · 운반/스택 수(12/20) · HP 바 · 런타임 3택 · 강화 버튼

## 11. MVP 범위 (6일)

**빌드 순서 (프로토타입):**
이동 → 공격 → 웨이브 스폰 → 고기 드랍 → 픽업 → **개별 스택 부착** → 운반 한계
→ 귀환/판매 → 골드 → 강화 UI → 런타임 3택 → VIP 구조

**MVP 구성:** 타이틀 1 · 허브 맵 1 · 던전 맵 1 · 보스 조우 1 · 캐릭터 1 · 몬스터 3~4종+보스 1
· 고기 3등급 · 스택 시스템 · 자동 판매 · 골드 · 강화 4종 · 영구 강화 5~8 · 스킬 6~10 · VIP 예시 2~3

**MVP 이후로 미루는 것:** 깊은 경제/밸런싱 곡선 · 다수 던전 층/맵 테마 · 직원 고용 · 주문
매칭 · 고기 종류 대량 확장 · 장비/인벤토리 · 다수 보스/컷신
