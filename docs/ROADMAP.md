# 개발 로드맵 (Phase Plan)

> **v0.1 초안 — 기획 검토 전.** 목표 수준: 단순 MVP가 아닌 **퀄리티를 올린 베타/출시급**.
> Phase 경계·배치는 BIBLE §11 빌드 순서를 참고해 AI가 그은 것 — `(임의)` 표식 항목은 전부 기획 검토 대상.
> 각 Phase 끝은 **플레이 가능한 체크포인트** (임의). 기간은 팀 확정 후 기입.

## Phase 0 — 킥오프 (개발 시작 전 필수)

| 파트 | 할 일 |
|---|---|
| 전체 | DECISIONS **C1(세계관)·C2(두 화면 체제)** 확정 |
| 개발 | 엔진 확정, 프로젝트 셋업, 세로 해상도 규격 제안 |
| 아트 | 제작 방식 확정 → 개발과 **C3(픽셀 규격)** 협의 → 캐릭터 스타일 시안 1종 |
| 기획 | BIBLE 정독·확정 처리, BALANCE 초기 수치 채우기 |

**완료 기준:** C1~C3 결정 기록, 빈 프로젝트에서 세로 화면이 뜬다.

## Phase 1 — 던전 코어 + 시그니처 ★

| 파트 | 할 일 |
|---|---|
| 개발 | 세로 화면 이동(터치 조이스틱+키보드) → 자동 공격 → 슬라임 웨이브 스폰 → 고기 드랍·픽업 → **개별 스택 부착 + 운반 한계** |
| 아트 | 플레이어(idle/walk)·슬라임·고기 낱개/묶음 1차 (임시 도형 → 교체) |
| 기획 | 스택 한계·픽업·이동 페널티 수치 / 슬라임 스탯 (BALANCE) |

**완료 기준:** 슬라임 잡아서 등에 고기탑이 쌓이고, 한계에 도달하면 더 못 줍는 걸 눈으로 확인.
_(스택이 재밌는지 이 시점에 팀 전체가 판정 — 이 게임의 존재 이유 검증)_ (임의)

## Phase 2 — 루프 완성 (허브 연결)

| 파트 | 할 일 |
|---|---|
| 개발 | 허브 씬 + 던전↔허브 전환 → 판매대·손님 자동 구매 → 골드 획득 → 강화 오브젝트 4종(월드-인 게이지) |
| 아트 | 허브 타일·판매대·손님 1~2종·골드/코인·강화 오브젝트 상태 표현 |
| 기획 | 판매가·강화 트리/비용 곡선 1차 (BALANCE) |

**완료 기준:** 사냥→적재→귀환→판매→강화→재입장 한 바퀴가 끊김 없이 돈다.

## Phase 3 — 던전 깊이

| 파트 | 할 일 |
|---|---|
| 개발 | 적 3~4종(고블린·박쥐·오우거) → 런타임 스킬 3택1 → **죽음/손실 규칙**(런 획득물만 손실, 도입 시점은 기획 결정 대기 — Phase 3 배치는 (임의)) → 던전 심층 진행 |
| 아트 | 적 세트·스킬 아이콘·타격/픽업 이펙트 |
| 기획 | 적 스탯·스킬 풀 수치·심층 난이도 곡선 |

**완료 기준:** 죽을 위험이 실제로 있고, "더 쌓을까 vs 지금 귀환할까" 판단이 발생한다.

## Phase 4 — 보스·진행 콘텐츠

| 파트 | 할 일 |
|---|---|
| 개발 | 보스(bullet-hell 패턴) → VIP 주문 구조 → 진행 강화(심층 해금) 연결 |
| 아트 | 보스·VIP 연출(마법 주문 보드 등)·고기 3등급 구분 |
| 기획 | 보스 밸런스·VIP 보상 설계 |

**완료 기준:** 보스전이 성립하고, VIP 주문 1건을 수행해 큰 보상을 받는다.

## Phase 5 — 베타 품질화

| 파트 | 할 일 |
|---|---|
| 개발 | 온보딩/튜토리얼 흐름 → 사운드 연결 → 세로 UI 마감·해상도 대응 → 웹 빌드 배포(공유 링크) |
| 아트 | 타이틀·아이콘·이펙트 폴리시·사운드 방향 |
| 기획 | 전체 밸런스 패스·플레이테스트 주도·개선 백로그 |

**완료 기준:** 외부인에게 링크만 주면 설명 없이 플레이 가능한 수준. "베타"라 부를 수 있는 상태.
