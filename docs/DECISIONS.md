# 결정 기록 (Decision Log)

> **원칙: 기획 결정은 기획 파트장 소관이며 여기서 논의하지 않는다.**
> 이 문서에는 두 가지만 올린다:
> ① **파트 간 협의가 필요한 항목** (기획↔아트↔개발이 같이 정해야 하는 것)
> ② **파트 소관 항목의 결정 기록** (각 파트가 정하되, 정했으면 여기 남겨 전체가 알게)

## 협의 필요 — 열려 있음

| # | 항목 | 논의 파트 | 내용 |
|---|---|---|---|
| C1 | **세계관 컨셉 확정** | 기획↔아트 | "이세계(異世界) 정육점"으로 가는가? 톤·네이밍·아트 컨셉이 전부 여기 묶임. 확정돼야 아트 컨셉 시안 시작 가능 |
| C2 | **두 화면 체제 확정** | 기획↔아트↔개발 | 허브(2.5D 쿼터뷰) + 던전(탑다운 뱀서류) 구조로 최종 확정인가? 아트 공수 2배·개발 카메라/씬 2종의 근거가 됨 |
| C3 | **픽셀 규격·해상도** | 아트↔개발 | 캐릭터 기준 px(예: 32/48px), 세로 기준 해상도. 아트 제작 방식 결정 후 바로 협의 필요 — 없으면 에셋을 못 씀 |

_협의 항목이 새로 생기면 여기에 추가한다._

## 파트 소관 — 각 파트가 정하고 기록만

| 게임 엔진 | 개발 | 🟡 미정 (프로토타입은 Cocos 3.8.8로 잠정 — `game/`) |
| 아트 제작 방식 (AI/수작업/혼합) | 아트 | 🟡 미정 |
