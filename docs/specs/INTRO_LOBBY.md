# 인트로 + 로비 기획서

> 상태: **v0.1 초안 — 기획 컨펌 대기.** `(임의)` 표식은 AI가 채운 값이라 기획이 덮어쓸 수 있음.
> 관련: [BIBLE.md](../BIBLE.md) §4·§6·§10 / [DECISIONS.md](../DECISIONS.md)

## 1. 목적

게임 실행 직후의 흐름(인트로 → 로비 → 인게임)을 정의한다.
지금까지 문서에는 **마을↔사냥지대 연속 맵만** 있었고 타이틀·로비·세이브 개념이 없었다 — 이 문서가 그 앞단을 채운다.

## 2. 전체 흐름

```
앱 실행
   ↓
[로딩]
   ↓
세이브 데이터 있나?
   │
   ├─ 없음(최초 실행) → [인트로] → [로비]
   │
   └─ 있음            →           [로비]
                                    ↓
                         ┌──────────┴──────────┐
                    처음부터하기            이어하기
                         │                     │
                    (세이브 초기화)      (세이브 불러오기)
                         └──────────┬──────────┘
                                    ↓
                                 [마을]
                          (이후는 기존 연속 맵)
```

- **인트로는 최초 1회만** (결정) — 판정 기준은 세이브 데이터 유무
- 로비는 **인게임 연속 맵과 분리된 별도 화면** — BIBLE §4의 "씬 전환 없음" 원칙은 **인게임(마을↔사냥지대)에만** 적용된다

## 3. 인트로

### 내용 (환생 클리셰)

현실의 평범한 정육점 주인이 트럭에 치여 죽고, 이세계 정육식당의 붓처로 환생한다.
주인공 성격은 **금사빠 찐따** (BIBLE §6) — 톤은 코믹하게.

### 컷 구성 (임의 — 3컷 안)

| # | 그림 | 자막 방향 |
|---|---|---|
| 1 | 현실의 정육점에서 고기를 썰고 있는 평범한 주인공 | 평범한 일상 |
| 2 | 트럭 (충돌 순간은 직접 묘사하지 않고 암시) | 사고 |
| 3 | 낯선 이세계 정육식당에서 눈을 뜨는 주인공 | 환생·상황 파악 |

- 자막 문구는 미정 — 기획이 작성
- 톤 주의: 호러·그로테스크 금지 (BIBLE §5), 충돌은 화면 밖·암전 처리로 (임의)

### 규칙

| 항목 | 값 |
|---|---|
| 재생 시점 | **최초 1회만** (결정) |
| 스킵 | 스킵 버튼 제공 (임의) |
| 다시보기 | 없음 (임의) |
| "처음부터하기"로 초기화 시 재생 여부 | **미결 — 기획 결정 필요** |

### 제작 방식 — **미결 (가장 큰 공수 분기점)**

| 안 | 공수 | 비고 |
|---|---|---|
| A. 스틸컷 3장 + 자막 슬라이드 (권장, 임의) | 작음 | 아트 3장이면 끝. 웹빌드 용량 부담 없음 |
| B. 프리렌더 동영상(mp4) | 큼 | 웹빌드 용량·로딩 문제 |
| C. 엔진 내 연출 | 중간 | 현실세계·트럭 에셋을 따로 만들어야 함 |

> 팀이 비서 NPC를 공수 문제로 보류한 기준에 맞추면 **A안**이 일관적이다.

## 4. 로비

### 화면 구성

```
┌──────────────────────────┐
│                          │
│      (배경 일러스트)      │  정육점 내부 — 던전 입구가 보이는 구도
│                          │
│        게임 로고          │
│                          │
│   ┌──────────────────┐   │
│   │   처음부터하기    │   │
│   ├──────────────────┤   │
│   │     이어하기      │   │  세이브 없으면 비활성 (임의)
│   ├──────────────────┤   │
│   │      설정        │   │
│   ├──────────────────┤   │
│   │      종료        │   │  ⚠ 웹 빌드에서는 숨김 (임의)
│   └──────────────────┘   │
│                    v0.1  │  버전 표기 (임의)
└──────────────────────────┘
```

- 세로 **1080×1920** 기준 (C3 규격)
- 버튼은 세로 1열, 화면 하단~중앙에 배치 (임의)

### 버튼 동작

| 버튼 | 동작 | 비고 |
|---|---|---|
| 처음부터하기 | 세이브 초기화 → 마을 진입 | **기존 세이브가 있으면 삭제 경고 확인창 필수** (임의) |
| 이어하기 | 세이브 불러오기 → 마을 진입 | 세이브 없으면 비활성 (임의) |
| 설정 | 설정 팝업 | 내용 미정 — 사운드 on/off 정도 (임의) |
| 종료 | 앱 종료 | **웹 빌드에는 종료 개념이 없으므로 숨김** (임의) |

### 배경 아트 방향

- 참고 이미지: 정육점 내부에서 **던전 입구(포탈/엘리베이터)가 보이는 구도** — 게임의 두 축(정육점 + 던전)을 한 장에 담음
- ⚠ 참고 이미지는 **가로 구도**였음 — 실제로는 **세로 화면**이라 재구성 필요
- 팔레트는 BIBLE §5 마스터 팔레트 따름 (던전 바이올렛으로 포탈 강조)

## 5. 세이브 데이터 — 신규 개념

"이어하기"가 성립하려면 저장 항목이 정의돼야 한다.

| 저장 항목 | 근거 |
|---|---|
| 보유 골드 | 죽어도 유지되는 값 (결정 07-08) |
| 강화 레벨 3종 (공격력·이동속도·운반) | 영구 강화 (BIBLE §7) |
| 해금한 구역 목록 | 경계 게이트 해금 (BIBLE §7-c) |
| 인트로 시청 여부 | 최초 1회 판정용 |

- 저장 시점·방식(자동저장 주기 등)은 **개발 판단** — 미정

## 6. 미결 항목

- 인트로 제작 방식 (A/B/C) — **기획↔아트↔개발**
- 인트로 자막 문구 — 기획
- "처음부터하기" 시 인트로 재생 여부 — 기획
- 설정 팝업 내용 — 기획
- 로고 디자인 유무 — 아트

## 7. 파트별 할 일

| 파트 | 할 일 |
|---|---|
| 기획 | 제작 방식 확정 · 자막 문구 · 설정 항목 정의 |
| 아트 | 로비 배경(세로 구도) · 인트로 컷 3장 · 로고 · 버튼 프레임 |
| 개발 | 로비 씬 · 세이브 데이터 구조 · 인트로 재생/스킵 · 웹빌드에서 종료 버튼 숨김 처리 |
