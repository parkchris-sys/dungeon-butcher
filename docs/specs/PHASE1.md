## 목표

**시그니처(등 뒤 고기 스택)가 재밌는지 실물로 검증한다.**
허브는 껍데기(외관), 던전 코어는 진짜(기능)로 만든다.

## 범위

### 1. 맵 (킥오프 확정 반영)
- **씬 전환 없는 하나의 연속 맵** — **2D 쿼터뷰 통일**, **다이아몬드 형태**
- **마을(허브) = 맵 하단 코너**: 정육점 건물 · 판매대 배치 — **외관만, 상호작용 없음**
- 모바일 세로 기준 (+PC 웹 키보드) / 조작: 이동만 (터치 조이스틱 + WASD/방향키)

### 2. 사냥 지대 진입 (구 "던전 입구")
- 마을 위쪽 **영역 경계를 넘으면 사냥 지대가 그대로 펼쳐짐** (화이트아웃 서바이벌식) — 입장 동작·로딩 없음
- 경계는 눈에 읽히게 표시 (게이트/아치 등 비주얼 — 형태는 아트 제안) (임의)
- 귀환: 걸어서 마을로 돌아오면 끝 — 별도 귀환 장치 없음

### 3. 던전 코어 ★ 검증 대상
- 슬라임 웨이브 스폰 — **우르르 몰려오는 물량전** 느낌 (탕탕특공대류, 결정)
- 자동 공격 — 근접 **핵앤슬래시 타격감** (결정), 조작 개입 없음
- 처치 → **드랍율%에 따라** 고기 **개별 오브젝트**가 바닥에 드랍 → **걸어가서 밟아야(근접) 픽업** (결정)
- **픽업 즉시 등 뒤 스택에 부착** ★ — 인벤토리 숫자가 아니라 눈에 보이는 한 조각으로:
  1~10개 개별 스프라이트, 살짝 흔들림(관성), 이후 묶음 압축 (BIBLE §3)
- **운반 한계**: 도달 시 바닥 고기를 더 줍지 않음 + "가득참" 표현
- **XP 보석 (결정)**: 처치 시 작은 보석이 **자동으로 캐릭터에게 날아와** 흡수 — 걸어갈 필요 없음, 플레이 방해 금지
- **런 레벨/택1 (결정)**: XP로 레벨업 → **택1 팝업 표시**.
  팝업 내용물(스킬)은 추후 Phase — Phase 1은 빈 상태로 뜨고 닫히기만 하면 됨.
  **빈 팝업에서 크래시 절대 금지** — 임시 선택지 1개("계속하기")로 처리 (임의)
- 슬라임 반격·플레이어 HP·죽음: **Phase 1 제외** — 죽음 도입 시점은 기획 결정 대기 (임의)

## 완료 기준

1. 세로 화면에서 마을(하단 코너)을 걸어다닌다
2. 마을 경계를 넘으면 로딩 없이 사냥 지대가 이어지고, 걸어서 마을로 돌아올 수 있다
3. 슬라임을 잡으면 등에 고기탑이 쌓이고, 한계에 도달하면 더 못 줍는다
4. 처치로 XP가 차고, 레벨업 시 택1 팝업이 뜨고 닫힌다 — **빈 상태에서 크래시 없음**
5. 팀 전체가 플레이해 보고 **"스택이 재밌는가"를 판정**한다 (임의)
