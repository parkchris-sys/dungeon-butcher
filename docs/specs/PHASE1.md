## 목표

**시그니처(등 뒤 고기 스택)가 재밌는지 실물로 검증한다.**
허브는 껍데기(외관), 던전 코어는 진짜(기능)로 만든다.

## 범위

### 1. 마을 허브
- 쿼터뷰 2.5D 허브 맵 1개, **모바일 세로** 기준 (+PC 웹 키보드)
- 배치물: 정육점 건물 · 판매대 — **외관만, 상호작용 없음**
- **던전 입구 — 유일하게 기능함**: 닿으면 던전으로 진입
- 조작: 이동만 (터치 조이스틱 + WASD/방향키)

### 2. 던전 (Phase 1 임시 형태)
- **뷰 전환 (결정)**: 허브 2.5D 쿼터뷰 → 던전 진입 시 **2D 아이소메트릭 뷰**.
  전환 연출은 Phase 1에선 최소(페이드 등)로 하되 이질감 없이 — "한 게임" 체감은 이후 Phase에서 폴리시
- 던전 구조(C4: A/B/C)는 **미결** — Phase 1은 **임시 단일 전투장**으로 구현하고,
  코어 시스템은 어느 구조로 확정돼도 재사용한다 (임의)
- 귀환: 전투장 내 귀환 지점을 밟으면 허브로 복귀 (임의 — 구조 확정 시 재설계)

### 3. 던전 코어 ★ 검증 대상
- 슬라임 웨이브 스폰 — **우르르 몰려오는 물량전** 느낌 (탕탕특공대류, 결정)
- 자동 공격 — 근접 **핵앤슬래시 타격감** (결정), 조작 개입 없음
- 처치 → 고기 **개별 오브젝트** 드랍 → 근접 시 픽업
- **등 뒤 개별 스택 부착**: 1~10개 개별 스프라이트, 살짝 흔들림(관성), 이후 묶음 압축 (BIBLE §3)
- **운반 한계**: 도달 시 바닥 고기를 더 줍지 않음 + "가득참" 표현
- **런 레벨/택1 (결정)**: 처치 시 XP 획득 → 레벨업 → **택1 팝업 표시**.
  팝업 내용물(스킬)은 추후 Phase — Phase 1은 빈 상태로 뜨고 닫히기만 하면 됨.
  **빈 팝업에서 크래시 절대 금지** — 임시 선택지 1개("계속하기")로 처리 (임의)
- 슬라임 반격·플레이어 HP·죽음: **Phase 1 제외** — 죽음 도입 시점은 기획 결정 대기 (임의)

## 완료 기준

1. 세로 화면에서 허브를 걸어다닌다
2. 던전 입구 → 전투장 진입, 귀환 지점 → 허브 복귀가 된다
3. 슬라임을 잡으면 등에 고기탑이 쌓이고, 한계에 도달하면 더 못 줍는다
4. 처치로 XP가 차고, 레벨업 시 택1 팝업이 뜨고 닫힌다 — **빈 상태에서 크래시 없음**
5. 팀 전체가 플레이해 보고 **"스택이 재밌는가"를 판정**한다 (임의)
