# 시스템 카드 — 시스템별 한 장 요약

> **어느 문서를 볼지 모르겠으면 여기서 시작한다.**
> 지금까지 문서는 종류별(바이블·밸런스·결정·인계)로 나뉘어 있었다. 그래서 "판매가 어떻게 돌아가는지"를 알려면 4개 문서를 돌아다녀야 했다.
> 종류별 구조는 **만들 때**는 맞지만 **이해할 때**는 틀렸다. 이 문서는 **시스템 하나당 카드 한 장**이다.
>
> **규칙: 수치를 여기에 복제하지 않는다.** 정본(BALANCE.md·BIBLE.md)의 위치만 가리킨다 — 복제하면 반드시 어긋난다.
> 작성 2026-07-24 · 기준 = 각 문서 현행 (버전 핀 금지)

**상태 표기** — ✅구현 완료 · 🔧구현됨/조정 대기 · 📋기획만 (미구현) · ⏸보류

## 1. 사냥 · 전투 ✅

**한 줄** — 사냥지대에서 몰려오는 동물을 자동공격으로 처치한다. 조작은 이동뿐.

| | |
|---|---|
| 소모 | HP (접촉 피격) |
| 획득 | 고기 드랍 기회 (→ 카드 2) |
| 주기 | 상시 — 던전 존 안에서 웨이브 자동 스폰 |
| 동작 | 웨이브 스폰(화면 밖) → 몬스터가 플레이어 추격 → 사거리 내 자동공격(넉백) → 접촉 시 피격(무적시간 동안 무피해) → HP 0이면 사망 |
| 죽음 | 그 런에서 얻은 고기 전부 손실, 마을에서 풀피 부활 |
| 수치 위치 | `BALANCE.md` §Phase 1 v0.3 (플레이어·닭·웨이브 표) |
| 상세 | `BIBLE.md` §8 · `specs/PHASE1.md` §3 |

| 직군 | 할 일 | 볼 곳 |
|---|---|---|
| 기획 | 몬스터 2종(4번째·보스) 확정 — **C8 미결** | DECISIONS |
| 개발 | 완료 (닭 1종). 종류별 스탯 확장은 표 확정 후 | `CombatSystem.ts` |
| 아트 | 동물 몬스터 시안 (닭·돼지·소 확정분) | BIBLE §5 팔레트 |

## 2. 고기 드랍 · 픽업 ✅

**한 줄** — 처치한 동물이 확률로 고기를 바닥에 떨군다. 걸어가서 밟아야 줍는다.

| | |
|---|---|
| 소모 | 없음 (이동만) |
| 획득 | 생고기 → 즉시 등짐 적재 (→ 카드 3) |
| 동작 | 처치 → 드랍율 판정 → 바닥에 고기 오브젝트 → 픽업 범위 안으로 걸어가면 획득 |
| 규칙 | **자동 흡수 아님** — 직접 주우러 가야 한다 (운반이 핵심 재미이므로) / 바닥 고기 소멸 없음 |
| 수치 위치 | `BALANCE.md` §닭(드랍율·수량) · §플레이어(픽업 범위) |
| 상세 | `BIBLE.md` §8 |

| 직군 | 할 일 | 볼 곳 |

| 개발 | 완료 | `CombatSystem.ts` |
| 아트 | 고기 낱개 스프라이트 | ASSET_LIST |

## 3. 운반 — 등짐 스택 ★시그니처 ✅

**한 줄** — 주운 고기가 등 뒤에 한 조각씩 눈에 보이게 쌓이고, 쌓일수록 느려진다.

| | |
|---|---|
| 소모 | 이동속도 (개당 절대값 감소) |
| 획득 | — (운반 자체가 목적) |
| 동작 | 픽업 즉시 등 뒤 스택에 부착(관성 흔들림) → 운반 한계 도달 시 더 못 주움("가득참" 표시) |
| 규칙 | **생고기·구운 고기 혼재 가능** (조각 색으로 구분, 한계는 공용) |

| 수치 위치 | `BALANCE.md` §플레이어(무게 페널티·운반 한계) |

## 4. 조리 — 그릴 🔧

**한 줄** — 생고기를 그릴에 넘겨 굽는다. 구운 고기는 플레이어가 직접 지고 나른다.

| | |
|---|---|
| 소모 | 등짐의 생고기 |
| 획득 | 구운 고기 (등짐에 재적재) |
| 주기 | 상시 — 트리거 발판 위에 서 있는 동안 |
| 동작 | 그릴 트리거 진입 → 생고기 한 조각씩 이송 → 자동 조리 → **수령 트리거를 밟아 구운 고기를 등에 재적재** |
| 규칙 | **자동 서빙 아님** — 플레이어가 직접 운반해야 한다 (운반이 핵심 재미) |
| 수치 위치 | `BALANCE.md` §조리·판매 시스템 수치 (이송·조리 시간) |
| 상세 | `BIBLE.md` §9-a |
| 🔧 상태 | 트리거는 구현됨. 개발이 신설한 `player-resource` 트리거 조합으로 위 플로우 재조립 예정 |

## 5. 판매 🔧

**한 줄** — 구운 고기를 판매대로 넘기면 손님이 사가고 골드가 오른다.

| | |
|---|---|

| 획득 | 골드 |
| 주기 | 상시 — 판매 트리거 발판 위에 서 있는 동안 |
| 동작 | 트리거 진입 → 구운 고기 한 조각씩 판매대로 순차 이송 → 대기 손님이 사감 → **골드 즉시 상승** |
| 이탈 | 존을 벗어나면 이송 정지 — 안 넘어간 고기는 등짐에 남고, 재진입 시 이어서 재개 |

## 6. 손님 ✅ ⚠상충

**한 줄** — 손님이 줄을 서서 기다리다가 요리를 받고 값을 치른다. 오래 기다리면 화내고 떠난다.

| | |
|---|---|
| 소모 | — |
| 획득 | 골드 (→ 카드 5) |
| 주기 | 스폰 트리거가 주기적으로 생성 |
| 동작 | 스폰 → 대기열 타일 따라 한 칸씩 이동(앞 손님 막으면 정지=줄서기) → 줄 끝에서 요리 대기 → 받으면 만족 → 값 지불 → 퇴장 타일로 나감 |
| 인내 | 성향(급함·느긋함·시간무한)별 참을성 → 소진되면 기분 1단계 하락(행복함>보통>지루함>화남, 머리 위 이모티콘) → **화남에서 또 소진되면 포기하고 퇴장** |
| 우선순위 | 먼저 온 손님(spawnId 작은 쪽) 우선 응대 |
| 수치 위치 | 코드 임의값 (참을성·성향·스폰 주기) — **BALANCE 이관 필요** |
| 상세 | `BIBLE.md` §9-b |
| ⚠ 상충 | **타일당 손님 1명 vs 2명** — 코드는 1명, 문서(§9-b·DECISIONS)는 2명. **기획 확정 필요** |
